# Transformation Roadmap

Owner: Operations & Transformation Partner. Follow consult-operating-system.

## Method
1. **Set the ambition.** Give a quantified target with a date (e.g. "+X pp EBITDA margin by FY2028"), broken down into workstreams.
2. **Structure the workstreams.** Use 4–7 workstreams, each with a lead, a value target, initiatives and KPIs. Inputs come from consult-initiative-prioritization.
3. **Phase the work in waves:**
   - Wave 0, mobilise (0–3 months): governance, baseline, quick wins.
   - Wave 1, build: the core changes.
   - Wave 2, scale and embed.
   Every wave has stage-gate criteria.
4. **Milestones and dependencies.** Show them on a Gantt-style timeline by quarter, and mark the critical path.
5. **Resourcing.** Cover FTEs, budget, external support, and the capacity clashes with business-as-usual.
6. **Governance.** Set up a transformation office, the steering committee cadence, the initiative stage-gates (idea → validated → planned → executed → realised) and value tracking that FP&A signs off.
7. **Change management:**
   - a stakeholder plan, handed to consult-stakeholder-alignment;
   - a communications calendar;
   - training;
   - quick wins for momentum.
8. **Risks.** Hand the top roadmap risks to consult-risk-mitigation.

## Output
- A one-page roadmap on a timeline.
- A workstream charter for each workstream.
- A milestone and dependency table.
- The governance model.
- A value-tracking template.
- The first 100-day plan.
