# Strategic Option Generation

Owner: Strategy Partner. Follow consult-operating-system.

## Method
1. **Anchor.** Start from the key question, the success criteria and the situation SCR.
2. **Generate broadly** before evaluating. Aim for 8–12 raw options, using several lenses:
   - **Where to play × how to win.** Where to play covers segment, geography, channel and value-chain step. How to win covers cost, differentiation, focus and ecosystem.
   - **Growth ladder:** core optimisation, adjacency, then new business. Include M&A, partnerships, JVs and licensing.
   - **Inversion:** what would a new entrant or a Chinese low-cost rival do?
   - **"Do nothing" and "radical"** options, as benchmarks.
3. **Cluster into 3–5 coherent options.** Each is a combination of choices, not a single tactic, and the options must be mutually exclusive as strategies.
4. **Define evaluation criteria in advance and weight them:**
   - value (NPV or EBITDA uplift);
   - strategic fit;
   - feasibility and capabilities;
   - risk;
   - time to impact;
   - capital need;
   - reversibility.
5. **Score each option**, with the evidence for every score. Run the "what would have to be true" test on the top 2.
6. **Recommend.** Give the preferred option, the conditions it depends on, and the no-regret moves to start now.

## Output
- An option long-list.
- 3–5 option profiles. Each has a one-line thesis, the choices it makes, value, risks and requirements.
- A scoring matrix.
- A recommendation with signposts.
- A hand-off to consult-business-case and consult-war-gaming.
